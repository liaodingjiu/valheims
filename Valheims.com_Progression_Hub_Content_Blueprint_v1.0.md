# Valheims.com Progression Hub Content Blueprint v1.0

## Document Purpose

This document defines the content strategy and data blueprint for:

    https://valheims.com/progression/

The goal is to create a central Valheim progression knowledge hub that
connects existing guide pages and helps Google understand Valheims.com
as a complete Valheim guide resource.

------------------------------------------------------------------------

# 1. Content Positioning

## Primary User Intent

Target question:

> What should I do next in Valheim?

The page should solve:

-   Where should I go next?
-   Which biome comes next?
-   Which boss should I fight?
-   What gear should I craft?
-   What resources should I collect?
-   What should I unlock before moving forward?
