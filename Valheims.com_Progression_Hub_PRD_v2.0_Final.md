# Valheims.com Progression Hub PRD v2.0 Final

## 1. Product Goal

Create the central Valheim progression navigation hub.

The page should help players answer:

> What should I do next in Valheim?

The goal is to make Google understand that Valheims.com is a complete
Valheim knowledge hub connecting:

-   Boss progression
-   Biome progression
-   Equipment progression
-   Survival systems
-   Crafting systems

------------------------------------------------------------------------

# 2. URL Strategy

Create a new page:

    /progression/

Do not replace existing pages:

-   /boss-order.html
-   /biome-guide.html
-   /armor-guide.html
-   /best-weapons.html
-   /beginner-guide.html

Existing pages become supporting resources.

------------------------------------------------------------------------

# 3. Page Positioning

## Page Type

This is NOT:
