1. How to Install Mods — BepInEx + Thunderstore

[ AdSense Ad Unit — Responsive Rectangle ]

BepInExPack Valheim (v5.4.2333+) is the essential modding framework. Every mod depends on it. The easiest way to install and manage mods is via a mod manager:

  1. Download r2modman (free, from Thunderstore.io) or Gale (alternative mod manager)
  2. Select Valheim as your game
  3. Create a profile → search and install mods with one click — dependencies are handled automatically
  4. Launch Valheim via the mod manager (select "Start Modded")

For manual installation: download BepInEx from Thunderstore, extract to your Valheim game folder, then place individual mod .dll files in BepInEx/plugins/.

Additionally, install Jötunn (Jotunn) — a library required by many content mods alongside BepInEx.

2. What About Valheim Plus?

⚠️ Valheim Plus is effectively dormant as of 2026. Its last meaningful update was in late 2024. It does not work with Valheim 1.0 or Deep North unless you lock your game to an older Steam beta branch — sacrificing all new content. Nearly every feature Valheim Plus offered now has a maintained standalone replacement. Skip Valheim Plus and use individual BepInEx plugins instead.

8. Compatibility & Troubleshooting

[ AdSense Ad Unit — Responsive Rectangle ]
  • Crossplay and mods are mutually exclusive. Crossplay uses PlayFab networking — BepInEx cannot hook into it. Everyone must be on Steam with crossplay disabled.
  • Most gameplay mods require both server and client installation with matching versions.
  • Use r2modman to share mod profiles via export codes. This ensures everyone has identical versions.
  • If the game crashes on launch, check BepInEx console output — 90% of crashes are version mismatches.
  • Restart your server weekly to clear memory buildup from mods.
