1. How to Enable the Console

[ AdSense Ad Unit — Responsive Rectangle ]
  1. Right-click Valheim in Steam → Properties → General → Launch Options → type -console
  2. Launch the game, press F5 to open the console
  3. Type devcommands and press Enter to activate all cheats
  4. A confirmation message appears — cheats are now active
⚠️ Important: Cheats work in single-player only by default. On multiplayer servers, you must be the server host or have admin privileges + a server devcommands mod. Using cheats marks your save as "admin mode" and may disable Steam achievements.

3. Spawn Command Format

[ AdSense Ad Unit — Responsive Rectangle ]
spawn [ItemName] [Amount] [Level] [p/e/i]

p = place in inventory, e = equip instantly, i = spawn in front of player. For creatures, Level 1 = no stars, 2 = 1★, 3 = 2★. Item names are case-sensitive.

Examples: spawn Wood 50 / spawn Bread 10 p / spawn MaceIron 1 e / spawn Wolf 3 2 (3 wolves at 1★)
