👥 Playing Valheim With Friends

Valheim supports multiplayer for up to 10 players. Whether you want casual co-op or a persistent world, there is a setup that works for your group.

You can play Valheim multiplayer in three ways: host a local world and invite friends via Steam (simplest option), set up a dedicated server for a 24/7 persistent world, or join a community server. Each method has trade-offs in cost, complexity, and uptime.

When hosting locally, the host's PC runs the world — if the host goes offline, the world stops. A dedicated server runs independently, allowing any player to join at any time. Boss difficulty scales with the number of nearby players, so multiplayer boss fights are harder but more rewarding.

🖥️ Dedicated Server Guide

A dedicated server keeps your world online 24/7 so friends can play any time — no host required.

Dedicated servers are ideal for groups who play at different times, long-term worlds, or communities. The server runs independently on Windows, Linux, or Docker. You can host it on your own hardware, rent from a provider, or use a cloud VPS. Complete dedicated server setup guide →

✅ Benefits

Always online, no host dependency, better performance for large groups, full admin control, world backups, and mod support.

⚠️ Requirements

Port forwarding (UDP 2456-2458), static IP or DDNS, 4GB RAM minimum, basic command line knowledge for Linux setup.

🔗 Valheim Crossplay Guide

Valheim supports crossplay between Steam, Xbox, PlayStation 5, and Nintendo Switch 2. Full crossplay guide →

Crossplay must be enabled in your server settings — it is not on by default. When enabled, players from any platform can join using a join code or server IP. Note that some mods break crossplay compatibility. Cross-progression is limited: your character and world are tied to the platform they were created on unless you manually transfer save files.

🤝 Co-op Tips For Better Multiplayer

🌍 World Sharing

Only the host needs to progress the world. Boss kills and map markers are shared. Share resources by building a central storage area with labeled chests.

📈 Progression Sync

Boss kills are world-wide. Coordinate boss fights so everyone is present — players who miss a boss kill must summon again to get the Forsaken Power.

💬 Communication

Use in-game chat, Steam voice, or Discord. Ping the map (middle mouse button) to mark locations for teammates. Share portal tags for fast travel.

💾 Backup Saves

Regularly back up your world files — especially before boss fights or major building sessions. Dedicated servers can automate backups with scripts.

🔧 Multiplayer Problems & Fixes

Common issues and solutions. See all known issues →

🔌 Connection Failed

Most common issue. Check: server is running, port forwarding is correct (UDP 2456-2458), firewall allows Valheim, and your friend has the correct IP or join code.

👻 Server Not Visible

If your server does not appear in the community list, ensure it is set to "Public" and the Steam game server ports are open. It can take 5-10 minutes to appear.

🔄 Version Mismatch

All players must be on the same game version. Update Valheim on Steam/Xbox/PS5. Dedicated servers update via SteamCMD. Modded servers require matching mod versions.

🐌 Lag & Performance

Reduce draw distance, lower shadow quality, and cap FPS. On dedicated servers, ensure adequate RAM and CPU. Large bases with thousands of instances cause FPS drops for all players.

❓ Frequently Asked Questions

Can you play Valheim multiplayer?
Yes, Valheim supports multiplayer for up to 10 players. You can host a world locally and invite friends via Steam, set up a dedicated server for a persistent 24/7 world, or join community servers. Valheim works well in both single-player and co-op — but many players feel it is especially fun with friends because building, exploring, and boss fights become more social and less punishing. Multiplayer basics →
How do I invite friends to my Valheim world?
Start a world, check "Start server" and set a password if you want privacy. Friends can join through your Steam profile (right-click → Join Game), by searching the server name in the community list, or by using a join code if crossplay is enabled. You can also make the server public or keep it private depending on your setup. Multiplayer setup guide →
How many players can join a Valheim server?
Valheim supports up to 10 players on a single server by default. Boss HP and enemy damage scale with the number of nearby players, so larger groups face tougher fights — but also have more hands for combat, resource gathering, and base building. Some third-party hosts may offer higher slot counts, but the game is officially designed around small groups.
What is the difference between a hosted world and a dedicated server?
A hosted world only runs while the host player is online and running that world — if the host goes offline, nobody can play. A dedicated server runs independently 24/7 and anyone can join at any time. Hosted worlds are simpler for small friend groups who always play together. Dedicated servers are better for groups who play at different times or want persistent access. Server setup guide →
Does Valheim support crossplay?
Yes, Valheim supports crossplay between Steam (PC), Xbox, PlayStation 5, and Nintendo Switch 2. Crossplay must be enabled in server settings — it is off by default. Join codes work across all platforms. Some players prefer to disable crossplay for the smoothest connection on PC. Modded servers may break crossplay compatibility. Complete crossplay guide →
Does progress carry over in multiplayer?
Yes. World progress — everything built, collected, or defeated — stays with that world. Boss kills are shared across all players on the server. Your character data (inventory, skills, Forsaken Powers) stays with you, which means you can bring the same character into different worlds. This is useful for bringing gear from your main world to help a friend's new world.
