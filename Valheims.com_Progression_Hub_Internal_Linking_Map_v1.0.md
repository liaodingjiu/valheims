# Valheims.com Progression Hub Internal Linking Map v1.0

## Document Purpose

This document defines the internal linking architecture for:

    https://valheims.com/progression/

The goal is to transform Valheims.com from a collection of individual
guide pages into a structured Valheim knowledge hub.

The progression page acts as the central topic hub.

------------------------------------------------------------------------

# 1. Internal Linking Strategy Overview

Current situation:

    Homepage
     |
    Many isolated guides

Target structure:

                     Homepage
                        |
                Progression Hub
                        |
     ------------------------------------------------
     |          |          |          |              |
    Bosses   Biomes    Equipment  Survival     Technical
     |          |          |          |              |
    Guides   Guides    Guides     Guides       Guides

The `/progression/` page becomes the semantic center.

------------------------------------------------------------------------
