Valheim Crossplay Guide 2026 — Is Valheim Cross-Platform?

Yes, Valheim supports full cross-platform multiplayer across Steam, Xbox, and PC Game Pass — with PS5 and Nintendo Switch 2 coming with the 1.0 launch. This guide covers everything: platform compatibility, step-by-step crossplay setup, Join Code troubleshooting, cross-progression rules, and what to do if your group wants mods.

1. Quick Answer: Is Valheim Cross-Platform?

[ AdSense Ad Unit — Responsive Rectangle ]

Yes, Valheim supports full cross-platform play across Steam, Xbox, and PC Game Pass (Microsoft Store). PlayStation 5 and Nintendo Switch 2 crossplay will be available with the Valheim 1.0 launch in 2026. Here's how it works:

  • Host enables Crossplay — check the "Crossplay" box when starting a world, or add -crossplay to your dedicated server launch flags.
  • Host shares the 6-digit Join Code — found in the pause menu (peer-to-peer) or server console (dedicated server).
  • Friends join using the code — "Join Game" → "Add Server" → enter the Join Code. That's it.
  • No port forwarding needed — crossplay uses PlayFab networking, which handles NAT traversal automatically.
  • Mods are incompatible with crossplay — if your group uses mods, everyone must be on Steam with crossplay off (see section 6 for your options).

3. How to Set Up Crossplay — Step by Step

[ AdSense Ad Unit — Responsive Rectangle ]

Option A: Peer-to-Peer (Host Your World)

  1. Start Valheim and select your character.
  2. Click "Start Game" → select your world, or "New" to create one.
  3. Check the "Crossplay" box before starting the world.
  4. Once in-game, press Esc → look for the 6-digit Join Code at the top of the pause menu.
  5. Share this code with your friends (any platform).
  6. Friends: "Join Game" → "Add Server" → enter the Join Code → "Connect."

Option B: Dedicated Server with Crossplay

  1. Add -crossplay to your server launch flags. Example:
    valheim_server -name "My Server" -world "MyWorld" -password "secret" -crossplay
  2. Start the server — wait 30-60 seconds for full initialization.
  3. Find the Join Code in the server console output:
    Join code: XXXXXX
  4. Share the Join Code with all players.
  5. Players connect: "Join Game" → "Add Server" → enter code.
💡 Pro Tip: Running a dedicated server with -crossplay gives you the best of both worlds — 24/7 uptime for your world AND cross-platform access without port forwarding. The Join Code bypasses the need to share your IP address. See our Dedicated Server Guide for full setup instructions.

Crossplay Setup Checklist

  • Host: Crossplay box is checked (or -crossplay flag is set on server)
  • Host: 6-digit Join Code is visible and shared with all players
  • All players: Enter Join Code via "Join Game" → "Add Server"
  • Verify: All players appear in-game
  • Mod check: If using mods → disable crossplay, all players must be on Steam (see section 6)

5. Cross-Progression Rules

[ AdSense Ad Unit — Responsive Rectangle ]

Valheim's cross-progression (carrying your character and progress between platforms) is partial. Here's exactly what works and what doesn't:

From → ToSteamXboxMS Store / Game Pass
Steam✅ Same account❌ Not supported❌ Not supported
Xbox❌ Not supported✅ Same account✅ Via Xbox cloud save
MS Store❌ Not supported✅ Via Xbox cloud save✅ Same account
🔑 Key Takeaway: Xbox and Microsoft Store share progress through Xbox cloud saves — play on your Xbox, continue on your PC via Game Pass, and vice versa. Steam characters and worlds are completely separate and cannot be transferred to or from any other platform. If you plan to play on both console and PC, the Microsoft Store / Game Pass version gives you the most flexibility.

6. Crossplay & Mods — Your Two Options

Crossplay and mods cannot be used together. Crossplay uses PlayFab networking, which BepInEx (Valheim's mod loader) cannot hook into. And Xbox / Microsoft Store clients cannot load mods at all. You have two paths:

Path A: Cross-Platform GroupPath B: Modded Group
Who can playSteam + Xbox + Game Pass (any mix)Steam only (everyone)
Mods❌ No mods allowed✅ Full mod support (BepInEx)
SetupEnable Crossplay + share Join CodeDisable Crossplay + all install same mods via r2modman
Server typePeer-to-peer or dedicated with -crossplayDedicated server with BepInEx (no -crossplay)
Best forMixed-platform friend groups, vanilla gameplayGroups that want QoL mods, new content, or custom difficulty

How to Switch Between the Two

You can switch a world from crossplay to modded (or vice versa), but it requires coordination:

  1. Crossplay → Modded: Everyone must own the game on Steam. Host unchecks Crossplay, all players install matching mods via r2modman, restart the world.
  2. Modded → Crossplay: Remove all mods from server and clients. Host checks Crossplay, share Join Code. Xbox/MS Store players can now join.
  3. World file is shared: The world save itself is compatible with both modes — your buildings and progress persist regardless of which mode you're in.
⚠️ Important: If you switch from modded to crossplay, any mod-added items, creatures, or structures in your world will be missing or broken. Do this only if you're willing to lose mod content.

7. Frequently Asked Questions

[ AdSense Ad Unit — Responsive Rectangle ]

Q: Is Valheim cross-platform on PS5?

Valheim will launch on PlayStation 5 alongside the Version 1.0 release in 2026. Iron Gate Studio has confirmed the PS5 version is in development. Once released, PS5 players will be able to crossplay with Steam, Xbox, and PC Game Pass through the standard Join Code system. Until then, PS5 players cannot join Valheim games.

Q: Is Valheim cross-platform PS4 and Xbox?

No. Valheim is not releasing on PS4 — the console release is for PlayStation 5 only. If you're on Xbox (One or Series X|S), you can already crossplay with Steam and PC Game Pass players using the Join Code method.

Q: Can Steam and Xbox play Valheim together?

Yes. This is the most common crossplay scenario and it works seamlessly. The host (on either platform) enables Crossplay and shares the 6-digit Join Code. The other player enters the code in "Join Game" → "Add Server." Both players will see each other in-game within seconds.

Q: Is Valheim cross-platform with mods?

No. This is a hard limitation — crossplay and mods are mutually exclusive. Crossplay uses PlayFab networking that BepInEx cannot hook into, and console clients cannot load mod files. If your group wants mods, everyone must play on Steam with crossplay disabled. See section 6 for a full comparison of your two options.

Q: Why is my Valheim Join Code not showing up?

The most common causes: (1) Crossplay isn't enabled — double-check the "Crossplay" box or -crossplay flag. (2) On a dedicated server, the code takes 30-60 seconds to appear after startup. (3) Firewall or antivirus blocking PlayFab traffic. (4) The pause menu Join Code location changed in a recent update — check both the main console output and the pause menu. See section 4 for the full troubleshooting table.

Q: Does Valheim support cross-progression / cross-save?

Partially. Characters and world progress transfer between Xbox consoles and the Microsoft Store (PC Game Pass) version through Xbox cloud saves — you can play on your Xbox, then continue on your PC. However, Steam is completely separate — Steam characters cannot be transferred to Xbox, Microsoft Store, or any other platform, and vice versa. If cross-progression matters to you, play the Microsoft Store / Game Pass version.

Q: Crossplay vs dedicated server — which is better?

They serve different needs. Crossplay (Join Code) is best for quick sessions with mixed-platform friends — zero setup, no port forwarding, works instantly. Dedicated servers are better for 24/7 worlds, large groups, or modded gameplay — but require technical setup (see our Server Setup Guide). You can combine both: a dedicated server with -crossplay flag gives you 24/7 uptime AND cross-platform access.

Q: Is Valheim on Nintendo Switch?

Valheim is not available on the original Nintendo Switch and likely never will be due to hardware limitations. However, a Nintendo Switch 2 version is expected alongside the Valheim 1.0 launch in 2026, with full crossplay support through the Join Code system.
